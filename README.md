# 深渊牌誓（暂定名）

手机网页竖屏卡牌地下城 Roguelike：选择职业、构筑卡组、探索随机路线，战斗后获得卡牌、遗物或事件奖励。

- 规模目标：3 职业 · 100 张卡牌 · 40 种敌人
- 设计与开发文档：[docs/DESIGN.md](docs/DESIGN.md)（附录 C 为实现进度）

## 当前版本 v0.1

- 3 个职业、全部 100 张卡牌、30 件遗物中的 29 件、12 种药水
- 第一层「沉骨墓窟」完整可玩：13 种敌人（含 3 精英、1 Boss）、9 个事件、商店、休息点、宝箱
- 自动存档（刷新 / 杀进程后可继续）、可输入种子、卡牌图鉴
- 美术暂用 emoji 占位

## 开发

```bash
npm install
npm run dev        # 本地开发，手机与电脑在同一局域网时可用手机访问终端里显示的地址
npm test           # 引擎单元测试 + 三职业各 80 局自动对局冒烟测试
npm run build      # 类型检查并输出静态文件到 dist/
npm run sim        # 贪心机器人粗测第一层难度
```

## 目录

```
src/engine/   纯逻辑引擎（无 DOM 依赖）：战斗、整局流程、随机数、状态
src/data/     卡牌、敌人、遗物、药水、事件、职业数据
src/ui/       Preact 界面（竖屏）
tests/        单元测试与模拟机器人
```
